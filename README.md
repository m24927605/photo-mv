# 照片MV

圖示原稿為 `src/assets/icon.svg`；`npm run icons` 產生 PNG／Windows ICO，macOS 另產生 ICNS。程式與 Windows 安裝檔均使用此圖示。

離線桌面照片音樂影片編輯器，目標為 Windows 10／11 64 位元。依目前指示，先在 macOS 實測核心功能。

## 啟動

Windows 使用者：執行 `dist/照片MV-0.1.0-Windows-x64-Setup.msi` 安裝；影片編碼器已隨附，不必安裝 Node 或 FFmpeg。MSI 由 GitHub Actions 的 Windows runner 建置；安裝與啟動驗證和完整編輯功能驗收分別記錄。

從原始碼開發需要 Node.js 22+。npm 會安裝目前平台的影片編碼器；測試檢查輸出另需系統 ffprobe（macOS 可 `brew install ffmpeg`）。

```sh
npm ci
npm start
npm test
npm run test:desktop
npm run test:functional
npm run build:win
```

MSI 建議在 Windows 建置；repo 的 `Windows MSI` workflow 會編譯並測試安裝、啟動與解除安裝。完成後可從該次 workflow 的 `photo-mv-windows-msi` artifact 下載安裝檔。

左上「專案」提供新專案、開啟專案、儲存專案及另存專案；快捷鍵 Ctrl+N／O／S（macOS 用 Cmd）。第一次儲存選擇 `.celebration` 檔案，之後儲存更新同一檔。「另存專案」（Ctrl/Cmd+Shift+S）建立副本並切換到新檔，保留原檔。切換有未儲存變更的專案時，可儲存、捨棄或取消。專案保存編輯設定及來源路徑，照片與音樂須留在原處。

點選照片、按 Shift 點另一張可選取區間；照片軸取得焦點時 Ctrl+A（macOS 亦支援 Cmd+A）全選。照片與音樂分成獨立區塊，時間位置仍對齊；照片區塊內的軸上方提供「全選照片」及「照片顯示時間長度」，只修改已選照片。選取照片後按 Delete／Backspace 刪除選取照片，輸入文字或數值時不會刪除照片。未選照片保持原秒數；新加入照片初始為 3 秒。

加入照片 → 在照片軸拖曳排序、拖曳片段左右邊緣調整秒數 → 按「＋文字」，直接在畫面文字框內打字 → 用浮動工具列調整字體、顏色、px 字級、粗斜體與底線 → 拖曳文字框定位。

文字框內可以直接按住拖曳，單擊選取框，雙擊或按 Enter 編輯；不需要拖曳符號。邊框游標為四向移動。拖曳時顯示十字線、中央／三等分參考格及對齊吸附線；Alt 暫停吸附，Esc 取消這次拖曳。

文字工具列提供「上一步」「下一步」「刪除」，只影響文字時間區塊，不改照片與音樂；刪除最後一段文字後仍可回復。點預覽區空白處收起工具列與外框，文字內容仍顯示。

文字從新增時間點延續到後續照片。在某個時間點修改內容、位置或樣式，便從該點建立新區塊，前段保持原樣，後段延續新設定直到同一段文字的下一次明確修改；刪除也從目前時間起生效。刻度上的「字」可回到區塊開始。區塊隨照片排序及調整時間，超出縮短後照片長度的區塊暫不顯示。

照片軸與音樂軸共用時間刻度。匯入音樂後直接點擊音樂區塊，可在來源聲波圖拖曳選取框及左右邊界裁切、調音量與淡入淡出；「試聽」使用影片預覽播放設定後的聲音。音樂不納入文字步驟。移除音樂的 × 位於音樂區塊右上角；未加入音樂時不顯示多餘提示。

「播放」開始／停止影片；「回到開始」停止播放並讓播放軸回到綠色開始軸。共用紅色播放軸可拖曳定位。綠色「開始」軸與橘色「結束」軸貫穿照片、音樂區塊；拖曳即生效，兩軸外的內容變暗，預覽與匯出只保留中間範圍，不需要確認按鈕。可隨時將兩軸拉回，照片／音樂編輯內容與原始檔均保留。

新專案預設 UHD 4K，支援 480p、720p、1080p、QHD 2K、UHD 4K。原圖唯讀、完整容納不裁切。MP4 為高畫質有損 H.264；RGB MOV 為合成影格無損 H.264，播放器相容性較低。中文需系統具備對應字體。無損不代表低解析照片可還原成高解析，也不代表保存 HDR／原始色域。

自動儲存保留本機恢復快照；具名專案檔需按儲存才會更新。編輯自動儲存於本機，重開會恢復照片、音樂、文字、時間軸、文字復原與編輯位置，包含尚未離開文字框的輸入。修改後約 250 毫秒送出儲存，完成時顯示「已儲存」；正常關閉會先完成最後一次儲存。異常中止可能失去最後尚未寫入的瞬間操作。原始照片／音樂需留在原路徑。照片總長定義可用時間軸；影片總長以開始與結束軸之間為準。長音樂截至影片結束，短音樂循環，不因音樂較長而增加黑畫面。目前為未簽章測試版安裝包，實際驗證範圍見 [狀態](docs/status.md)。

## 公開原始碼範圍

此 repo 包含程式碼、設計／實作／驗收文件、測試程式、測試 fixture 與不含私人素材的測試摘要。使用者照片、音樂範例、`.celebration` 專案、UI 截圖、錄影、依賴目錄與安裝產物保留在本機，不納入 Git。文件中的部分本機驗收證據連結因此不隨 repo 提供；執行測試後會在 `docs/test-results` 產生紀錄。`test/projects-native.cjs` 另需自行準備本機 `範例素材`，其他自動測試使用 repo 內的 fixtures。
