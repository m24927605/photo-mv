# 照片音樂影片編輯器：設計文件

版本：0.1／2026-10-16。狀態：實作基準，尚未正式發布。

## 產品與範圍

提供離線桌面應用程式。交付目標為 Windows 10／11（x64），依使用者最新指示先在 macOS 做完整功能實測；Windows 執行結果須獨立記錄。使用者匯入多張 JPEG、PNG、WebP，調整照片順序及每張時間，匯入一段 MP3、WAV、M4A 音樂，在預覽畫面安排跨照片延續的文字區塊，復原編輯，最後輸出 MP4。第一版採直接切換，不加入轉場、雲端、帳號、AI 放大或多音軌。

新專案解析度預設 UHD 4K；重開仍保留儲存的解析度。新增照片初始為 3 秒，不提供全域預設時長設定。照片軸單選、Shift 區間複選，照片軸取得焦點時 Ctrl+A／Cmd+A 全選；輸入欄內保留文字全選。焦點在照片軸或照片工具列時，Delete／Backspace 刪除所選照片；文字編輯、數值輸入與輸入法組字不攔截，按住連發不連續刪除相鄰照片。刪除僅移除專案片段，原始檔不變。照片與音樂分成獨立區塊並維持時間位置對齊，照片區塊內的軸上方工具列提供全選按鈕與照片顯示時間長度，只批次修改已選照片。每張照片可調整 0.1–14400 秒（專案合計最多 4 小時），精度 0.1 秒。畫面固定 16:9、30 fps，完整容納照片並以黑邊補滿，不裁切。照片總長定義可用時間軸；影片總長以開始與結束軸之間為準，未調整兩軸時涵蓋全部照片。音樂不足循環，音樂較長截至影片結束，不增加黑色尾段。未匯入音樂則輸出無聲影片。照片軸與音樂聲波軸上下對齊共用時間刻度；照片可拖曳排序，每張左右邊緣可拖曳調整時間。點軸進入對應編輯，點刻度移動播放位置。

## 畫質契約

原圖只讀，不覆寫、不先行壓縮。預覽可縮小，但輸出必須重新解碼原圖，以目標尺寸繪圖；禁止把預覽縮圖放大輸出。中間影像使用無損 PNG。

| 選項 | 實際尺寸 |
| --- | --- |
| 480p | 854×480 |
| 720p | 1280×720 |
| 1080p | 1920×1080 |
| 2K（QHD） | 2560×1440 |
| 4K（UHD） | 3840×2160 |

2K 在本產品明確指 QHD，不是 DCI 2048×1080。一般 MP4 使用 H.264 CRF 16、yuv420p 與 AAC 320k，屬高畫質有損編碼。另提供 H.264 RGB CRF 0 無損編碼選項（MOV），只保證合成後 RGB 影格無損，不等於保留照片原始色域、HDR、EXIF 或原始解析度；播放器相容性須另外驗收。低解析度原圖不會因 4K 輸出而增加細節。

## 編輯模型與互動

每張照片保存資產 ID、名稱、秒數與文字陣列。文字儲存中英內容、字體、顏色、相對畫面高度字級、粗體／斜體／底線與正規化位置。文字從新增時間延續到後續照片。修改內容、位置或樣式便在當下建立新區塊，前段不變，後段延續至同一段文字的下一次明確修改；空陣列代表清除文字。時間精度 30 fps，跨解析度維持相對位置。區塊附著照片相對時間，隨照片排序；照片縮短時超出長度的區塊暫不顯示。

採小畫家式文字流程：按「＋文字」直接在畫面輸入。工具列提供字體、px 字級、顏色、B／I／U、「上一步」「下一步」「刪除」，可按住工具列把手移出預覽區。文字框內容、空白及邊框都能直接拖曳；單擊選框，雙擊或按 Enter 編輯，位移達 4 個畫面像素才開始拖曳。邊框游標為四向移動。移除文字框專用拖曳符號與紅色 ×。點預覽區空白處隱藏工具列與外框，文字內容保留。

拖曳顯示跟隨框中心的十字線、中央與三等分格線。文字框左／中／右及上／中／下距離畫面或其他文字參考點 6 個畫面像素內可吸附；Alt 暫停吸附，Esc 或視窗失焦取消這次拖曳。移動及放開由整個視窗處理，移出原文字框放開仍須提交新位置。參考線不進入影片。

上一步／下一步按照片隔離，不影響排序、時間或音樂。一次拖曳提交一步；文字離開輸入框後提交一步。退回後的新文字編輯清除該照片的下一步。刪除最後文字後工具列仍保留前後步驟按鈕。前後步驟記錄隨專案及自動儲存恢復。文字輸入框中的 Ctrl/Cmd+Z 保留原生輸入復原。

預覽使用原生純文字編輯區與共用 Canvas 繪圖，輸出重新以原圖繪圖；編輯框、工具列與參考線不會輸出。Windows 字體為微軟正黑體／新細明體／標楷體，macOS 為蘋方／宋體／楷體，另提供 Arial／Georgia／Times New Roman。

音樂編輯器採單首音樂：可拖曳起點／終點裁切、調整 0–100% 音量、設定淡入／淡出與試聽。來源聲波圖以單一選取框圈住保留範圍，框身拖曳移動，左右邊界拖曳裁切。音樂軸顯示實際輸出聲波（含裁切、循環與淡化）。裁切段落不足影片長度時循環；淡入淡出依整支影片起訖處理。預覽與輸出使用同一份設定，音樂操作不進入文字復原記錄。點擊音樂區塊展開音樂面板，不提供額外編輯音樂按鈕。移除音樂的 × 位於音樂區塊右上角，有音樂才顯示；移除「未選音樂」佔位文字。

介面僅保留操作、標籤與必要狀態。左上 +照片／+文字／+音樂，右上解析度／格式／匯出，水平對齊。移除左側照片清單及「檢查照片」訊息。

編輯後最多每 250 毫秒送出本機自動儲存，包含未離開文字框的內容；顯示儲存中／已儲存／儲存失敗。正常關閉先完成最後寫入，異常中止後重開自動恢復最後成功快照。保存照片順序／時間、文字與復原記錄、音樂設定、輸出設定、播放位置與工具列位置。以同目錄暫存檔寫入、sync、原子替換，避免半份 JSON 蓋掉完整快照。壞檔保留並明確報錯，不自動覆蓋。照片與音樂以來源路徑恢復，原始檔必須仍在原處；原始照片與音樂永不覆寫。尚未完成寫入的最後瞬間操作不保證在強制終止後保留。

預覽區隨視窗剩餘空間放大，維持 16:9，照片與音樂收合時可同時看到兩軸。字級以所選輸出解析度的 px 表示；內部保存相對高度，切換解析度時按比例換算 px。

左上專案選單及原生選單支援新建、開啟、儲存（Ctrl/Cmd+N／O／S）及另存（Ctrl/Cmd+Shift+S）。`.celebration` 文件保存編輯狀態、文字復原、UI 狀態及來源絕對路徑，不嵌入原始媒體。首次儲存使用原生視窗，後續原子替換同一檔；自動儲存仍獨立運作，不代表命名專案已更新。新建／開啟遇到未儲存內容，提供儲存、捨棄、取消；儲存取消或失敗則中止切換。開啟前完整驗證，壞檔不得替換目前內容。命名專案的自動恢復同時保留檔案路徑及未儲存狀態。

## 架構與安全

Electron 主程序負責檔案對話框、只讀資產存取、受控暫存檔及 隨附 FFmpeg 子程序。renderer 負責編輯與共享 Canvas 合成。preload 僅提供白名單 IPC；停用 Node integration，開啟 context isolation/sandbox，CSP 禁止遠端內容，拒絕外部導覽及新視窗。主程序驗證 IPC 來源、資產 ID、解析度、數量、時長與 PNG 尺寸，不能接受任意檔案路徑或 shell 指令。

匯入失敗不得破壞已編輯資料。輸出使用來源快照、鎖定編輯，逐張產生 PNG，避免一次保存所有 4K 解碼影像。FFmpeg 使用參數陣列啟動，不經 shell。音樂先將選取段落解碼成暫存 PCM，再使用 amovie 串流循環，避免舊版 FFmpeg 無限輸入循環在結束時卡住，不需把整段音樂解碼留在記憶體。輸出到目的地同目錄暫存檔，成功後才替換使用者選定的目的檔；失敗或取消保留既有目的檔並清除暫存。禁止輸出覆蓋任何匯入來源。匯入單檔限制 100 MiB；專案最多 300 張／總長 4 小時。極大像素圖片仍可能消耗大量記憶體，屬 release gate 必驗項。

## 共用播放軸與範圍剪裁

紅色共用播放軸可在照片／音樂軸拖曳與刻度定位；Home／End 及方向鍵亦可定位。綠色「開始」軸、橘色「結束」軸貫穿照片與音樂區塊，附可見標籤並可拖曳／鍵盤調整；0.1 秒精度，至少保留 0.1 秒。不提供數字欄、設點或保留範圍按鈕。

拖曳即保存專案 selection 並直接影響預覽與匯出。兩軸外內容變暗，原時間軸內容保留，可隨時拉回調整。預覽從開始軸播放，到結束軸停止；影片總長顯示兩軸間的長度。範圍始終限制於照片時間軸。

匯出建立獨立快照：照片取範圍交集，音樂取同一原時間段，保留循環相位、音量及淡化，使用本機 PCM WAV。輸出快照不覆蓋編輯專案，原始媒體、照片長度、文字及文字復原記錄不變。範圍隨專案自動儲存，重開恢復。

播放控制為「播放／停止」及「回到開始」；返回會停止聲音與播放，回到有效開始軸。尚未完成的音訊啟動也須取消，避免返回後被舊請求重新播放。

另存使用原生儲存視窗，預設「原檔名 副本.celebration」；成功後切換目前專案路徑與標題。不得另存至目前專案同檔或其別名，也不得覆寫素材來源。取消或失敗時不切換路徑。另存後的普通儲存更新新檔；本機自動恢復快照與具名文件儲存分開。

選框狀態按 Delete／Backspace，與工具列刪除共用處理，刪除整個目前文字框；編輯狀態及數值／選單輸入保留原生刪字作用。忽略按鍵連發及輸入法組字。新增文字後仍立即進入輸入狀態；選取狀態使用移動游標，編輯時使用文字游標。
