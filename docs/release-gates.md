# Release gate 標準

任一阻擋 gate 未通過即 NO-GO；不允許用風險接受註記掩蓋必需功能。0.1 開發預覽可啟動，不等於正式 release。

| Gate | 必須提供的證據 | 阻擋條件 |
| --- | --- | --- |
| G1 需求與契約 | 設計／實作／驗收一致，解析度、兩軸片長、px 字級及專案保存明確 | 承諾與實際不同，必需能力缺漏 |
| G2 程式驗證 | 模型、信任邊界、取消及真實 FFmpeg 測試全綠 | 任一測試失敗，僅 mock 輸出、未實測直接拖曳並放開、文字步驟、跨照片延續、分段預覽／匯出或音訊返回失效 |
| G3 圖像與聲音 | A01–A10、A14 的實際匯出及視聽紀錄 | 缺字、順序／尺寸錯誤、位置漂移、音樂失效 |
| G4 可靠性 | A11、A12、A15、A16；來源雜湊不變，失敗不損原檔 | 新建／開啟無提示遺失未儲存內容、壞檔破壞目前專案、未恢復最後成功快照、正常關閉遺失最後輸入、來源損壞、孤兒程序、無法取消 |
| G5 安全與無障礙 | A13、A17、依賴審查、無遠端追蹤 | 任意檔案存取／指令執行，核心操作不可鍵盤使用 |
| G6 安裝交付 | Windows 安裝與啟動；含可用 FFmpeg、授權清單、字體權利、版本資訊 | 依賴開發機環境、缺必要授權或 binary |
| G7 最終凍結 | 凍結版本、完整一次回歸結果、已知限制、操作說明與回退方式 | 封存後修改未重驗，存在未結阻擋缺陷 |

交付目標為 Windows 10／11 x64。依使用者指示，本輪先完成 macOS 實際功能測試，Windows 安裝與執行保留待測，不得以交叉編譯成功代替。簽章／公證不列入這次功能驗收。效能以代表機器的峰值記憶體、磁碟需求及時間實測記錄，不預先杜撰數值。

每輪先凍結語意再做一次完整驗證；最多兩輪。預算到期保留最後可用版本並明列 blocker。沒有對應作業系統實機、安裝包或獨立播放器證據，對應 gate 必須寫「未驗證」，不可填通過。
